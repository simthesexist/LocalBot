| Renderer to Main IPC | Renderer requests network config + reach info via NETWORK_* invoke channels; main proxies to daemon JSON-RPC; renderer never reads state.json or network.json directly. |
| Renderer to Phone WS | Desktop renderer never sees the phone bundle — separate Vite target. The phone bundle has NO window.localbot access; it uses pure browser WebSocket API. |

| Tailscale state.json to Main | Tailscale state.json is in `%LOCALAPPDATA%\Tailscale\state.json` (user's own dir); read-only; never written by Localbot. Co-located process spoof risk is the user's own. |
| LAN to Main | When bindMode='lan', the WS server listens on 0.0.0.0; anyone on the user's LAN can connect. v1 ships WITHOUT WS auth (Pitfall 1); Tailscale ACL is the recommended access control. |
