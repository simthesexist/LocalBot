# Plan 03-02 — Surface completion: chokidar refresh + full UI per UI-SPEC + audit coverage

**As a** Localbot user,
**I want to** see the workspace tree update automatically after a tool call, switch between past sessions, view a diff of an edit_file result inline, and open the bot's memory in a modal,
**so that** the Phase 3 surface area is complete — every locked UI-SPEC element renders and every locked IPC event fires.

## Objective

Expand the Wave 1 tracer slice into the full Phase 3 surface area:

1. **Chokidar watcher** — `daemon/watcher.cjs` watches `<userData>/workspace/default/` and `<userData>/bots/default/`; main bridges its `tree:refresh` event to the renderer. Renderer re-invokes `tree:list` on every event so changes show up within 500 ms (UI-08).
2. **Renderer UI per UI-SPEC** — full `DiffView` (Split/Unified toggle + binary placeholder), `MemoryPanel` (modal with markdown + facts + Escape/backdrop close), `SummaryBlock` (head-of-file bubble variant), `SessionSwitcher` (header dropdown listing sessions newest-first + active marker).
3. **State slices** — `sessions.ts` for the session list + current session id; extend `memory.ts` and `tree.ts` to subscribe to events.
4. **Cancel mid-summarize** — `runSummarizer` derives a child AbortController from the user's cancel signal so canceling mid-summary aborts only the summary, never the outer loop (LLM-04).
5. **Audit log coverage** — every new op (`memory.read`, `memory.write`, `tree.list`, `memory.update`, `tree.refresh`) writes a JSONL line with the canonical Phase 2/3 shape (SEC-04).
6. **Test coverage** — extend the 6 Wave 0 unit suites with the cases the Wave 1 stubs left implicit (cancel mid-summarize, chokidar refresh latency, memory cap eviction, session listing).

## Purpose

The tracer proved the architecture. Wave 2 closes the surface area: every UI-SPEC element renders, every IPC event fires, every audit line lands, every Wave 0 test gap from VALIDATION.md is filled.

## Output

- `DiffView`, `MemoryPanel`, `SummaryBlock`, `SessionSwitcher` components fully wired to the state slices.
- `chokidar` watcher + IPC bridge active; workspace tree refreshes within 500 ms of file changes.
- Cancel mid-summarize works: outer `streamChat` retry is NEVER triggered when the summary is canceled.
- All 6 Wave 0 Vitest suites fully cover the requirements from VALIDATION.md.
- Audit JSONL coverage for every new op.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> IPC | Untrusted renderer; cannot directly invoke daemon tools, write user filesystem, or drive chokidar |
| main -> daemon (JSON-RPC) | Main owns the agentic loop + IPC bridge; system calls (memory/tree) bypass the per-bot allowlist |
| daemon -> filesystem | Daemon enforces `safePath` containment; chokidar watches confined to `<userData>/workspace/<bot>/` + `<userData>/bots/<bot>/` |
| daemon -> watcher (chokidar) | Debounced 250ms; emit `tree:refresh` notifications only via `sendNotification`; no direct fs writes |
| main -> LLM API | Summary call uses a child AbortController + separate retry budget; user cancel aborts summary only |
