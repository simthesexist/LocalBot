## Critical Anti-Patterns (do NOT repeat these)
- **Spawning `electron.exe <script.cjs>` without `ELECTRON_RUN_AS_NODE=1`** causes child to launch as fresh GUI app instead of running script. Symptom: stdout never emits script's NDJSON. Always set this env in `spawn()` for daemon subprocesses.
- **Dual `readline.createInterface()` on same stdout** buffers subsequent NDJSON lines until process exit. Use single readline with manual line splitting if needed.
- **`sendRequest` rejecting before `initialized` flips** is a chicken-and-egg gate — the `initialize` JSON-RPC call IS what flips `initialized`. Use a `bypassInitCheck` flag for the bootstrap handshake.
