       `checkBrowserUrl` pipeline in this EXACT order (Pitfall 5 / OWASP SSRF cheat sheet):
       (a) `new URL(url)` — on throw return `{allowed: false, reason: 'invalid_url'}`.
       (b) scheme allowlist — if !['http:', 'https:'].includes(parsed.protocol) return `{allowed: false, reason: 'scheme_denied', pattern: parsed.protocol}`.
       (c) DNS resolution — `await dns.lookup(parsed.hostname, {all: true})`; for each `{address}`, if isPrivateIp(address) && !ssrfAllowInternal return `{allowed: false, reason: 'ssrf_denied', pattern: address}`.
       (d) `parsed.pathname` glob check via picomatch: if Array.isArray(browserDeny) && browserDeny.length, run picomatch(browserDeny, {dot:true}); if match return `{allowed: false, reason: 'browser_deny', pattern: <first matching string from browserDeny using picomatch.isMatch>}`.
       (e) allowlist: if !Array.isArray(browserAllow) || browserAllow.length === 0 return `{allowed: false, reason: 'no_allowlist'}`; if !picomatch(browserAllow, {dot:true})(parsed.pathname) return `{allowed: false, reason: 'not_in_allowlist'}`.
       (f) return `{allowed: true}`.
