<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Daemon to Main IPC | Daemon emits `notification:scheduled-error` (one-way NDJSON notification); main's spawn.ts forwards as-is to the renderer; main's notifications.ts handleScheduledError is the canonical toast constructor. Renderer cannot drive this path. |
| Main to Renderer IPC | `EVENT_NAVIGATE_TO_BOT {botId}` is a main → renderer event; renderer calls setActiveBotId(botId). The event carries no privileged payload — just a bot id. |
| Electron Notification to OS | `new Notification(...).show()` fires through Windows Action Center (after setAppUserModelId); click event returns to the calling main process via Notification.on('click'). |
| BrowserWindow focus | main owns the BrowserWindow reference; click handler must call createMainWindow() if the window was closed/minimized/destroyed; renderer cannot focus the window itself (sandbox). |
