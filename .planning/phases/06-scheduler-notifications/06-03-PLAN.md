## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer to Main IPC (bots:update) | Renderer edits cron + cronEnabled + notifyOnError + scheduledPrompt via bots:update; main proxies to daemon's bots/update JSON-RPC. Main NEVER decides what's persisted. |
| Main to Daemon JSON-RPC | Main's spawn.ts proxies bots/update. The daemon's botLoader.writeConfigPatch is the canonical write; the scheduler is called AFTER the write succeeds. |
| Renderer subscribe to EVENT_NAVIGATE_TO_BOT | Notification click -> main webContents.send -> renderer setActiveBotId. The event payload carries only {botId} — no privileged action. |
| Fake M3 to Electron | E2E test points the app at fake-m3-server on localhost — the real Anthropic API is never reached. |
| Playwright to Electron | _electron.launch() drives the app via DevTools Protocol. UI clicks go through real DOM events. |
