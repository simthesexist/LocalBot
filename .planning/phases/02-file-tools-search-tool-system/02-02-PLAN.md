# Plan 02-02 — Multi-tool surface + agentic loop multi-turn resume

**As a** Localbot user,
**I want to** ask the bot to write, edit, and list files in its workspace and see the changes happen across multiple tool calls in one turn,
**so that** the LLM can chain operations (e.g., `write_file` then `read_file` to verify) without losing context.

## Objective

Expand the tracer slice from Plan 02-01 into three more tools (`write_file`, `edit_file`, `list_dir`) and wire the agentic loop's multi-turn resume so a single user message can drive N tool calls in series. The loop must:

1. Persist assistant text + tool_use blocks back into `messages`.
2. Append `tool_result` blocks as user-role content.
3. Re-call `streamChat` with the extended `messages`.
4. Bound the loop at `maxTurns: 10` to avoid runaway chains.

This is the **horizontal expansion** along the file-tool axis — every file path the phase touches is now covered, but `code_search` (ripgrep) stays in Wave 3 because it brings a new subprocess + binary resolution surface.

## Purpose

The tracer proved the architecture works for one tool. This plan proves it scales: (a) three more tools with distinct semantics (write/edit/list) all routed through the same allowlist + safe-path helpers, (b) the agentic loop's multi-turn shape (append tool messages, re-stream) works against a stubbed SDK stream, and (c) the audit log captures each tool's outcome with `tool_use_id` correlation. Plan 02-03 then layers code_search + UI polish on this proven base.

## Output

- Three real tool implementations (`write_file`, `edit_file`, `list_dir`) replacing the Wave 1 stubs.
- `edit_file` enforces single-match strict (Pitfall #6 / Open Question #2 from RESEARCH.md).
- `runAgenticLoop` correctly resumes with appended tool messages; bounded at `maxTurns: 10`.
- 4 new Vitest unit suites (write_file, edit_file, list_dir, agentic_loop) + extension to Playwright `daemon-tools.test.ts`.

### A. Implement `daemon/tools/write_file.cjs`

Replaces the Wave 1 stub. Pattern mirrors `read_file.cjs` but writes instead of reads:

```javascript
// daemon/tools/write_file.cjs
const fs = require('node:fs/promises');
const path = require('node:path');
const { safePath } = require('./safe_path.cjs');

async function call({ path: requested, content }, ctx) {
  if (typeof content !== 'string') {
    const err = new Error('content must be a string');
    err.code = 'invalid_content';
    throw err;
  }
  const resolved = await safePath(ctx.workspaceRoot, requested);
  await fs.mkdir(path.dirname(resolved), { recursive: true });
  try {
    await fs.writeFile(resolved, content, 'utf8');
    return { path: requested, bytesWritten: Buffer.byteLength(content, 'utf8') };
  } catch (e) {
    if (e.code === 'EACCES' || e.code === 'EPERM') {
      const err = new Error(`permission denied writing: ${requested}`);
      err.code = 'eacces';
      throw err;
    }
    throw e;
  }
}

module.exports = { call };
```

### B. Implement `daemon/tools/edit_file.cjs`

Replaces the Wave 1 stub. Single-match strict per RESEARCH.md Open Question #2 (decision: strict). Atomic via tmp + rename:

```javascript
// daemon/tools/edit_file.cjs
const fs = require('node:fs/promises');
const path = require('node:path');
const crypto = require('node:crypto');
const { safePath } = require('./safe_path.cjs');

async function call({ path: requested, find, replace }, ctx) {
  if (typeof find !== 'string' || find.length === 0) {
    const err = new Error('find must be a non-empty string');
    err.code = 'invalid_find';
    throw err;
  }
  if (typeof replace !== 'string') {
    const err = new Error('replace must be a string');
    err.code = 'invalid_replace';
    throw err;
  }
  const resolved = await safePath(ctx.workspaceRoot, requested);

  let content;
  try {
    content = await fs.readFile(resolved, 'utf8');
  } catch (e) {
    if (e.code === 'ENOENT') {
      const err = new Error(`file not found: ${requested}`);
      err.code = 'enoent';
      throw err;
    }
    throw e;
  }

  const occurrences = content.split(find).length - 1;
  if (occurrences === 0) {
    const err = new Error(`find substring not present in ${requested}`);
    err.code = 'no_match';
    throw err;
  }
  if (occurrences > 1) {
    const err = new Error(`find substring matches ${occurrences} times in ${requested} (single-match strict)`);
    err.code = 'multiple_matches';
    throw err;
  }

  const newContent = content.replace(find, replace);
  // Atomic write: tmp file in the same directory + rename (same-FS rename is atomic).
  const tmpPath = `${resolved}.localbot-tmp-${crypto.randomBytes(6).toString('hex')}`;
  try {
    await fs.writeFile(tmpPath, newContent, 'utf8');
    await fs.rename(tmpPath, resolved);
  } catch (e) {
    // Best-effort cleanup of the tmp file if rename failed.
    try { await fs.unlink(tmpPath); } catch {}
    throw e;
  }
  return { path: requested, replacements: 1 };
}

module.exports = { call };
```

### C. Implement `daemon/tools/list_dir.cjs`

Replaces the Wave 1 stub. Dirs-first then alpha sort, stable tiebreak by lowercased name then original:

```javascript
// daemon/tools/list_dir.cjs
const fs = require('node:fs/promises');
const path = require('node:path');
const { safePath } = require('./safe_path.cjs');

async function call({ path: requested }, ctx) {
  const resolved = await safePath(ctx.workspaceRoot, requested);
  let dirents;
  try {
    dirents = await fs.readdir(resolved, { withFileTypes: true });
  } catch (e) {
    if (e.code === 'ENOENT') {
      const err = new Error(`directory not found: ${requested}`);
      err.code = 'enoent';
      throw err;
    }
    throw e;
  }

  // Sort: dirs first (alpha), then files (alpha). Stable tiebreak by lowercased name.
  const entries = dirents
    .map((d) => ({
      name: d.name,
      type: d.isDirectory() ? 'dir' : d.isFile() ? 'file' : 'other',
      size: d.isFile() ? (d.size ?? null) : null,
    }))
    .sort((a, b) => {
      if (a.type === b.type) {
        const al = a.name.toLowerCase();
        const bl = b.name.toLowerCase();
        if (al === bl) return a.name.localeCompare(b.name);
        return al.localeCompare(bl);
      }
      return a.type === 'dir' ? -1 : 1;
    });

  return { entries };
}

module.exports = { call };
```

```typescript
import { streamChat, type StreamChatResult } from './client';
import { callTool } from '../daemon/spawn';
import { runWithRetry, classifyError } from '../errors';
import { DEFAULT_SYSTEM_PROMPT } from './prompts';
import { TOOL_SCHEMAS } from './tools';
import type { ChatMessage, MessageBlock } from '../../shared/types';

export interface AgenticLoopOptions {
  messages: ChatMessage[];           // initial messages (user turn)
  system?: string;                   // defaults to DEFAULT_SYSTEM_PROMPT
  tools?: Anthropic.Tool[];          // defaults to TOOL_SCHEMAS
  signal: AbortSignal;
  bot?: string;                      // default 'default'
  maxTurns?: number;                 // default 10
  onToken: (delta: string) => void;
  onToolUse: (b: {id: string; name: string; input: unknown}) => void;
  onToolResult: (r: {toolUseId: string; content: string; isError: boolean}) => void;
  onError: (e: Error) => void;
}

export interface AgenticTurnResult {
  text: string;
  blocks: MessageBlock[];
  toolCalls: Array<{id: string; name: string; input: unknown; output: string; isError: boolean}>;
  turns: number;
}

const MAX_AGENT_TURNS = 10;

function appendAssistantBlocks(messages: ChatMessage[], blocks: Anthropic.ContentBlock[]): void {
  const content: Anthropic.ContentBlock[] = blocks.reduce<Anthropic.ContentBlock[]>((acc, b) => {
    if (b.type === 'text') acc.push({ type: 'text', text: b.text } as Anthropic.TextBlockParam);
    else if (b.type === 'tool_use') acc.push({ type: 'tool_use', id: b.id, name: b.name, input: b.input } as Anthropic.ToolUseBlockParam);
    // Skip non-text/tool_use blocks (e.g., thinking) in the persisted thread.
    return acc;
  }, []);
  if (content.length === 0) return;
  // Typed carrier — no `(m as any)` cast. The shared ChatMessage type extends with
  // `anthropicBlocks?: Anthropic.ContentBlock[]` for round-trip; the SDK reads
  // it via streamChat's `messagesToParams` helper.
  messages.push({ ts: Date.now(), role: 'assistant', content: '', blocks: [], anthropicBlocks: content });
}

function appendToolResult(messages: ChatMessage[], toolUseId: string, content: string, isError: boolean): void {
  messages.push({
    ts: Date.now(),
    role: 'user',
    content: '',
    blocks: [],
    anthropicBlocks: [{
      type: 'tool_result',
      tool_use_id: toolUseId,
      content,
      is_error: isError,
    } as Anthropic.ToolResultBlockParam],
  });
}

export async function runAgenticLoop(opts: AgenticLoopOptions): Promise<AgenticTurnResult> {
  const tools = opts.tools ?? TOOL_SCHEMAS;
  const system = opts.system ?? DEFAULT_SYSTEM_PROMPT;
  const bot = opts.bot ?? 'default';
  const maxTurns = opts.maxTurns ?? MAX_AGENT_TURNS;
  const messages: ChatMessage[] = [...opts.messages];

  let aggregated = '';
  const blocks: MessageBlock[] = [];
  const toolCalls: AgenticTurnResult['toolCalls'] = [];
  let result: StreamChatResult | null = null;
  let turns = 0;

  await runWithRetry(
    async () => {
      aggregated = '';
      blocks.length = 0;
      toolCalls.length = 0;
      // Inside the retry: re-stream fresh — the outer messages persist across retries.
      const lastResult = await streamChat({
        messages,
        system,
        tools,
        signal: opts.signal,
        onToken: (delta) => {
          aggregated += delta;
          blocks.push({ kind: 'text', text: delta }); // partial; final blocks come from result.blocks
          opts.onToken(delta);
        },
        onToolUse: (b) => { blocks.push({ kind: 'tool_use', id: b.id, name: b.name, input: b.input }); opts.onToolUse(b); },
        onDone: () => {},
        onError: (e) => { opts.onError(e); },
      });
      result = lastResult;
      turns++;
      appendAssistantBlocks(messages, lastResult.blocks);
      // After the stream, dispatch tool_use blocks (if any) and resume.
      let stopReason = lastResult.stopReason;
      while (stopReason === 'tool_use' && turns < maxTurns) {
        const toolUseBlocks = lastResult.blocks.filter((b: any) => b.type === 'tool_use') as Anthropic.ToolUseBlock[];
        for (const tb of toolUseBlocks) {
          let output = '';
          let isError = false;
          try {
            const resp = await callTool(tb.name, tb.input as Record<string, unknown>, { toolCallId: tb.id, bot });
            // resp is JsonRpcResponse; on success resp.result is the tool's return value.
            const r: any = (resp as any).result;
            output = typeof r?.content === 'string' ? r.content : JSON.stringify(r ?? {});
          } catch (err: any) {
            isError = true;
            const code = err?.code ?? 'unknown';
            const message = err?.message ?? String(err);
            output = `Error: [${code}] ${message}`;
          }
          blocks.push({ kind: 'tool_result', toolUseId: tb.id, content: output, isError });
          opts.onToolResult({ toolUseId: tb.id, content: output, isError });
          toolCalls.push({ id: tb.id, name: tb.name, input: tb.input, output, isError });
          appendToolResult(messages, tb.id, output, isError);
        }
        // Re-stream with the appended messages.
        const next = await streamChat({
          messages,
          system,
          tools,
          signal: opts.signal,
          onToken: (delta) => {
            aggregated += delta;
            opts.onToken(delta);
          },
          onToolUse: (b) => { blocks.push({ kind: 'tool_use', id: b.id, name: b.name, input: b.input }); opts.onToolUse(b); },
          onDone: () => {},
          onError: (e) => { opts.onError(e); },
        });
        result = next;
        turns++;
        appendAssistantBlocks(messages, next.blocks);
        stopReason = next.stopReason;
      }
      if (stopReason === 'tool_use' && turns >= maxTurns) {
        const err = new Error(`agentic loop reached maxTurns=${maxTurns} without resolving`);
        (err as any).category = 'fatal';
        (err as any).retryable = false;
        opts.onError(err);
        throw err;
      }
    },
    {
      attempts: 3,
      baseDelayMs: 250,
      isRetryable: (e) => (e.category === 'transient' || e.category === 'network') && e.retryable,
    },
  );
}

// Convert internal ChatMessage[] to the Anthropic SDK's MessageParam[].
// Reads `m.anthropicBlocks` (typed carrier from the loop) as the SDK's
// `content`; falls back to plain `content` when `anthropicBlocks` is absent.
// Messages without either (legacy rows) become empty-content rows so the
// SDK does not reject the array.
function messagesToParams(messages: ChatMessage[]): Anthropic.MessageParam[] {
  return messages
    .filter((m) => m.content || m.anthropicBlocks)
    .map((m): Anthropic.MessageParam => {
      if (m.anthropicBlocks && m.anthropicBlocks.length > 0) {
        return { role: m.role as 'user' | 'assistant', content: m.anthropicBlocks as unknown as Anthropic.MessageParam['content'] };
      }
      return { role: m.role as 'user' | 'assistant', content: m.content };
    });
}

  // Trim streaming blocks; prefer the canonical result.blocks ordering.
  const finalBlocks: MessageBlock[] = result?.blocks
    ? result.blocks.map((b: any) =>
        b.type === 'text'
          ? { kind: 'text', text: b.text }
          : { kind: 'tool_use', id: b.id, name: b.name, input: b.input },
      )
    : [{ kind: 'text', text: aggregated }];

  return { text: aggregated, blocks: finalBlocks, toolCalls, turns };
}
```

The loop is bounded by `maxTurns` AND by the `runWithRetry` outer cap (3 attempts for the LLM call). It also stops if `opts.signal` aborts mid-stream.
